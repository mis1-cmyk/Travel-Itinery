# Travel-It — AI Travel Itinerary Planner

This folder contains the browser files publicly served by the deployed site:
https://travel-itinerary-rep-xafp.bolt.host/

## Deploy to GitHub Pages

1. Commit the contents of this folder to the root of a GitHub repository (or configure Pages to publish this folder).
2. In GitHub, open **Settings → Pages** and choose the branch and folder to publish.

The build uses relative asset paths, so it can be served from a project subpath. It is a compiled frontend bundle; the hosted page did not expose the original source modules, package manifest, or source maps. No backend source or secret credentials were included.

The app may call public third-party services from the browser. Those services remain subject to their own availability, terms, and rate limits.
